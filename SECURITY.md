# Security Policy

## Reporting a vulnerability

Report security issues privately through either route:

- Email: [moelzerpeter@proton.me](mailto:moelzerpeter@proton.me)
- [GitHub private vulnerability reporting](https://github.com/peterle95/shellfolio/security/advisories/new)

Please don't open a public issue for a vulnerability.

I aim to acknowledge reports within 7 days on a best-effort basis. There is no bug bounty.

I will not take legal action against good-faith research that avoids accessing other people's data, does not disrupt the site, and allows reasonable time for a fix before public disclosure.

## More information

Encryption, hosting, access controls, incident history, testing, and certification status are described at <https://petermoelzer-shellfolio.vercel.app/security>.
